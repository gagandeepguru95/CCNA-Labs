# CCNA Labs — Practice Repository

This repository contains my hands-on lab practice files as I work through the CCNA 200-301 certification syllabus.

Each folder corresponds to a specific topic and contains the Packet Tracer lab file along with a short note explaining what was practiced.

This repo contains my hands-on lab practice files as I work through 
the syllabus.

Learning resources I am using:

- Switch interfaces — interface status, show commands, interface configuration
